# Core Java ☕
### My Java Learning & Practice Journey

This repository documents my journey of learning, revising, and strengthening **Core Java** from the fundamentals to advanced concepts.

I am building this repository as a long-term learning record rather than simply collecting code. The goal is to understand how Java works, practice concepts by writing code, and gradually move from basic programming to **DSA, backend development, and Spring Boot**.

> This repository will evolve as I learn. New concepts, examples, notes, problems, and projects will be added over time.

---

## 🎯 Why I'm Building This

I already have experience with programming concepts, but I want to rebuild my Java foundation properly instead of relying only on theoretical knowledge.

The main objectives of this repository are:

- Strengthen my Core Java fundamentals
- Revisit concepts I have previously learned
- Practice by actually writing and modifying code
- Build a strong understanding of OOP
- Improve problem-solving through DSA
- Understand Java Collections deeply
- Learn how Java works internally
- Prepare for technical interviews
- Build a foundation for Java backend development
- Eventually move towards Spring Boot and distributed systems
