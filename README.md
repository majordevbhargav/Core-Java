# Core Java

- Strings

- Classes and objects
- Constructors

- Polymorphism
- Abstraction
- Interfaces
- Composition

### Core Java

- Collections
- Generics

- Lambdas

- Optional

- REST APIs
- Spring
- Spring Boot
- Spring Security
- Microservices
- System design
